# Resource sidecar fixture

Build `resource_fixture` through the [example index](../README.md). Generation
creates graphic frames and level data in the build directory; install the MBA
with its matching sidecar. A switches frames and long Back exits. Startup also
reads across the 256-byte resource cache boundary.

See [resources](../../docs/resources.md) for paths, collection formats, integrity
errors and installation. A packaged sidecar alone does not establish device
read performance or physical display correctness.

The runtime save ID is `resource_fixture` (`/extra/saves/resource_fixture.sav`).
